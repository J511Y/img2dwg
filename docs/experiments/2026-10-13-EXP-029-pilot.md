# EXP-029 · 준공도면–변경전 CAD 40개 pilot

- 날짜: 2026-10-13 KST, 당일 실행 기록
- 상태: 추출·자동 검사 완료 / 정합·직원 검수 대기
- 연구 분류: R&D 후보 — supervised pair 정합 가능성 및 crop 치수 보존 불확실성을 실행으로 조사했다. 모델 성능·학습 성공을 주장하지 않는다.
- 검토자·공식 확정: 확인 필요

## 질문·가설·사전 조건

준공도면+변경전후.dwg가 같은 의뢰 폴더에 있을 때, 변경전 영역을 뽑아 치수를 보존하고 이미지와 자동 정합할 수 있는가? seed 20261013, 60개 발견 후보 중 순차 처리, 추출 성공 40개/최대 시도 50개를 계획했다. 원본은 hash/size/mtime으로 검사하고 로컬 복사본만 수정한다.

## 실행·직접 결과

- 운영 워크 연결 인덱스: 8,764 entries. 정렬·shuffle 후 폴더 125개를 비재귀 조사해 정확한 파일명 후보 60개 발견.
- 실제 처리: 40개 시도, 40개 변경전 DXF/DWG 추출·ODA 재열기. 추출 실패 0. 조사 범위의 결과이며 전체 운영 성공률이 아니다.
- 치수: 40/40 DIMENSION multiset 보존 pass, 객체 913개. 측정값·기준점·text override·effective dimension style을 대조했다. measurement 예외 0, unit header 보존 40/40.
- 정합: exact viewport/long-side 1600 CAD render에 grayscale/edge SIFT, ratio 0.72, RANSAC 4px. 기준은 inlier 20/ratio .35/coverage .15/convex viewport 등이다. 38개 weak/degenerate, 2개 reliable match 없음. 자동 승인 후보 0, 직원 승인 0.
- 원본 CAD vs DWG 재열기 CAD의 동일 viewport render MAE: 최대 0.1183207667 (0~255 scale), 40개 측정. 같은 renderer의 시각 보존 신호이며 준공도면 정합이나 실물 정확도 증거가 아니다.
- raw local crop DXF handle 검사에 충돌 후보가 표시됐다. 상세 건수와 header/loader/재열기 구분은 동결한 [집계](../research/assets/2026-10-13-pilot-summary.json)의 `cad_integrity`와 비공개 sample receipt를 따른다. memory audit repairs는 저장하지 않았다.
- 최종 태그 검사는 DIMSTYLE의 block-name code 5와 handle code 105, HEADER HANDSEED와 실제 엔티티를 구분했다. 실제 entity duplicate는 crop/reopen 모두 0/40, crop header/loader 경고는 3/40이다. 초기 broad tag 집계의 후보 15개를 실제 엔티티 중복으로 확정하지 않는다.

## 방법·실패·수정

기존 crop detector의 변경전/후 text·sheet/inner frame 계약을 source hash와 함께 재사용했다. thumbnail 픽셀은 crop GT로 쓰지 않았다. source original과 before DXF/DWG, CAD render, feature matches, 원본 전후 hash, worker logs를 보존했다.

렌더 backend가 figure 크기를 finalize에서 변경하는 것을 발견해 drawing 후 해상도/viewport를 재설정하고 모든 샘플을 local snapshot에서 다시 렌더했다. degenerate homography mask도 보류 처리했다. 합성 known transform·치수 스타일/누락 guard와 파일 선택·render resolution 등 7개 unittest를 실행해 통과했다.

12개 대표 pair를 contact sheet로 시각 점검했다. 촬영 원근·접힘·희미한 청사진·복수 평면/설명·CAD 단순화 차이를 확인했다. coarse similarity를 정확한 동일 평면·치수 정합 승인으로 쓰지 않았다.

## 해석·다음 실험

crop/export의 치수 보존은 가능했지만, 사진 full-sheet와 정리된 CAD를 이 protocol의 SIFT/homography로 자동 gold 정합하는 가설은 지지되지 않았다. 학습용 split을 배정하지 않고 모두 pending으로 둔다. 입력 ROI/4개 이상 대응점·변경전 영역을 검수하고 종이 휨과 도면 자체 차이를 분리한다. CAD handle 경고의 block/reference 및 renderer/loader 영향을 추가 진단한다.
