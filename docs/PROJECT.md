# 프로젝트 목표 · 2026-10-13

## 최종 산출물

사진·스캔·래스터 평면도를 입력받아 실제 CAD에서 열고 엔티티 단위로 선택·수정·저장 가능한 DWG를 만든다. 사용자가 검수할 원본 대비 오버레이, 실패·불확실성 표시, 변환 근거와 run receipt를 함께 제공하는 것을 목표로 한다.

핵심은 **왜곡된 이미지에서도 치수·벽간 간격·연결 관계가 정확히 조율된 canonical 벡터 그래프**다. Jippin의 원본 좌표 segmentation 오버레이와 달리 관측 왜곡을 보존하는 tracing은 최종 목표를 충족하지 않는다. 사내 CAD geometry와 직원 확정 semantics를 연결해 structured decoder를 학습하는 전략은 [재조사 보고서](research/2026-10-13-domain-reassessment.md)를 따른다.

1차 범위는 2D 벽체·문·창·방 경계·주요 치수와 레이어다. 곡선·경사벽·기호·문자·블록 복원은 별도 축으로 평가한다. 구조적 안전성·법적 판단, BIM/3D, 변경 설계 자동 생성은 현재 범위에 포함되지 않는다.

## 해결할 불확실성

| 불확실성 | 확인 방법 |
| --- | --- |
| 워크 이미지와 DWG가 같은 상태·평면인가 | 변경 전후/시트/뷰포트 수동 판별 및 정합 샘플 검수 |
| 사진 왜곡과 얇은 선이 복원 가능한가 | 원해상도·타일·정규화 ablation과 난이도별 실패 분석 |
| 깨끗한 폴리곤이 편집 가능한 엔티티로 이어지는가 | 벽/개구부 관계, 중복·자기교차·곡선·레이어 검사 |
| 문헌 모델이 한국 사내 도면에 일반화하는가 | 건물·평면 계열 분리 holdout 및 스캔/사진 OOD |
| 이미지에서 절대 치수를 정할 수 있는가 | 알려진 치수/OCR/검수 anchor, scale unknown 처리 |
| 빠른 System-1 판단이 총비용을 낮추는가 | 동일 입력 rule/소형 분류기/Jev/Laya/VLM 비교와 E2E 품질 |
| DWG 변환이 실제 사용 CAD와 호환되는가 | 엔진·버전별 열기→수정→저장→재열기 receipt |

## 성공 판정

파일 생성, 기하 복원, 위상, CAD 사용성, 검수 시간, 총비용은 각각 보고한다. 한 숫자로 합쳐 실패를 감추지 않는다. 최종 판정은 [평가 프로토콜](EVALUATION.md)의 frozen holdout과 CAD roundtrip을 따른다.

정량 목표는 초기 baseline을 측정한 뒤 고정한다. 임시 목표와 실측을 분리한다. CPU-only, 특정 클라우드, 특정 모델 또는 기존 프로젝트 목표값을 이번 프로젝트의 제약으로 자동 승계하지 않는다.

## 기존 프로젝트 관계

- `data-pipeline`: 의뢰 폴더 인벤토리·이미지–DWG 페어·CAD-IR 설계의 재사용 후보. 미커밋 자료는 수집 시점 작업 트리이며 정합·엔티티 추출·재현성 재검증이 필요하다.
- `floor-plan-model-train`: 인식 모델·타일·데이터 라벨 경험 재사용 후보. 해당 segmentation 지표가 DWG 성능을 증명하지 않는다.
- 워크/ERP: 의뢰별 연결 폴더 위치의 정본. 기존 운영 흐름은 이 프로젝트 초기 세팅에서 변경하지 않는다.
- 연구노트: 프로젝트별 활동을 수집하고 같은 결과의 중복 계상을 방지한다.
