> **상태 갱신 (2026-10-13):** Jippin·직원 확정 라벨·HF 운영·기존 CAD-IR 자산을 직접 재조사했다. 이 문서는 최초 후보 목록이며 현재 프로젝트 적용 전략은 [사내 자산 기반 재조사 보고서](2026-10-13-domain-reassessment.md)를 우선한다.

상태: 문헌·공식 배포 페이지 조사. 다운로드·학습·추론·DWG 변환 실험은 미실행이다. 다음 내용은 후보 선정 근거이며 프로젝트 성능이 아니다. 최신 문서와 실제 계정 접근 가능성은 실행 전에 다시 확인한다.

## 핵심 관찰과 연구 설계

최근 직접 복원 연구는 마스크 후처리뿐 아니라 방·문·창의 폴리곤 시퀀스, 그래프 관계, 이미지 조건 구조화 출력을 사용한다. 이 프로젝트는 후보를 공통 CAD-IR와 writer로 연결해 비교한다. 방 polygon이 맞아도 벽 두께·door host·치수·레이어·곡선이 누락될 수 있어 실제 CAD 사용성은 별도 평가한다.

`Jev`와 `Laya`는 System-1 결정 모델이다. JEPA·LeJEPA·LLaDA는 별개의 연구 계열이며 서로 대체 이름으로 쓰지 않는다. 앞의 둘은 텍스트/JSON 상태의 bounded decision 후보, 뒤 계열은 표현학습·diffusion generation 후보로 나눈다.

## System-1: Jev와 Laya

- [TypeSafe 공식 문서](https://docs.typesafe.ai/introduction): Jev는 state와 typed questions를 받아 `choice`, `score`, `noul` 및 확률/확신도를 반환하는 System One model이다. 이미지나 CAD-IR 생성 지원을 이 문서에서 확인한 것으로 주장하지 않는다.
- [Laya 공식 model card](https://huggingface.co/convaiinnovations/laya): text-classification, Apache-2.0 open weights. English/multilingual/typed-decisions checkpoint 구분. [공식 코드](https://github.com/NandhaKishorM/laya)와 [HF demo Space](https://huggingface.co/spaces/convaiinnovations/laya-demo)를 확인했다. 공개 Space는 데모이며 사내 전용 managed Endpoint 배포·추론 성공은 확인하지 않았다.
- [2026-10 paired 연구](https://arxiv.org/abs/2610.02267): routing/agent decision의 후보 비교와 분석 오류 자체를 감사한다. zero-shot 결과를 일반화하지 말고 순서·후보 수·보정 split과 gate 비용을 포함하는 평가 설계의 근거로 사용한다.

프로젝트 적용은 OCR 요약·기하 오류 목록·confidence/quality feature를 비식별 JSON으로 만들어 후보 처리 경로 선택, 재시도 유형, 검수 우선순위를 판단하는 실험이다. 규칙·소형 supervised classifier·프론티어 VLM과 동일 상태에서 비교한다. CAD 구조 검사 실패를 모델 확률로 override하지 않는다. 비용에는 상태를 만드는 OCR/VLM 비용도 포함한다. 한국어 checkpoint·도메인 calibration·option order·unknown/abstain을 평가한다.

## 우선순위와 다음 조사

먼저 페어 정합과 GT writer를 검증하며 frontier/기하/Raster2Seq pilot을 준비한다. 이후 graph·segmentation·self-supervised encoder·diffusion·System-1 hybrid를 비교한다. 가장 새 모델을 무조건 최종 후보로 고르지 않는다. 모든 접근법은 [백로그](experiment-backlog.md)에 실험·실패·보류 이유를 남긴다.

남은 확인: dataset별 실제 이용허락·파일 접근·hash, FloorplanVLM 공식 weights/benchmark 배포, AIHub 정확한 데이터 ID, 실제 CAD 제품과 DWG 버전 분포, System-1 API 계정/버전, 사내 외부처리 허용·예산. 현재는 문서 작성과 연구 준비 단계다.
