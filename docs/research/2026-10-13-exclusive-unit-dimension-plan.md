# 전유부·방향·치수 중심 변환 계획 · 2026-10-13

사용자 추가 조건을 반영한 현재 계획이다. 기존 40개 pilot은 변경전 CAD 추출과 roundtrip 보존 증거이며 학습 정답 승인이 아니다. 전체 준공도면과 CAD의 특징점 정합은 중단한다. ROI 모델·반전 판별·치수 solver는 아직 구현하지 않았다.

## 복원 범위와 방향

출력은 해당 세대의 검수된 **전유부 평면**이다. 옆집·엘리베이터·공용 공간은 판단 문맥과 출력 범위를 분리한다. 도곽 crop과 전유부 선택은 별도 단계이며 기존 변경전 crop도 전유부 정답으로 자동 승인하지 않는다. 입력 ROI와 CAD target 경계를 각각 검수하고 포함/제외/미확정 영역을 기록한다. 경계벽·발코니·샤프트 등 애매한 요소는 직원이 업무상 작성 범위를 확인한다. 시각적 ROI를 법적 전유권 판정으로 취급하지 않는다.

원본 도면 방향, 사진 회전/원근 왜곡, 실제 세대 좌우반전은 별도 변수다. 정방향/반전 가설과 근거를 보관하고 현관·샤프트·비대칭 개구부, 의뢰 정보와 직원 확인으로 결정한다. 대표 준공도면만으로 실제 방향을 알 수 없으면 `orientation=unknown`으로 남긴다. 재투영 오차만으로 방향을 승인하지 않는다.

반전 시 geometry와 치수 측정점/관계·문 경첩/열림 방향을 변환한다. 길이 값은 유지하고 문자는 읽을 수 있게 다시 작성한다. 같은 평면의 정방향/반전 사례와 합성 변형은 split 간 섞지 않는다.

## 치수 원장과 완료 조건

전유부 복원에 필요한 표시 치수를 하나씩 원장에 등록한다. 원본 위치/이미지 근거, 판독 값·단위, 두 측정점, 중심선/벽 마감면/개구부 등 측정 기준, CAD entity 관계와 검수 상태를 연결한다. ROI 밖까지 걸친 연속 치수는 단순 절단으로 버리지 않고 대상 구조를 결정하는 관계를 확인한다. 제외 치수에도 이유를 기록한다.

상태는 `confirmed/unreadable/conflicting/excluded_with_reason`으로 구분한다. 판독 불가능 값을 임의로 채우지 않는다. 유도한 값은 표시 치수와 구별하고 유도식·직원 승인을 남긴다. 치수 체인 합계, 전체 폭/깊이, 벽 두께와 기준점 충돌을 검출한다.

승인은 다음 두 검사를 모두 요구한다.

1. **누락 검사:** 필요한 표시 치수 전체가 원장과 CAD 출력에 대응한다. 미판독·미해결 충돌은 완료를 막으며 사유 있는 제외와 구별한다.
2. **수치 검사:** 실제 vector endpoint 거리/투영 길이가 승인 값·단위와 사전 고정한 허용 오차 내에서 맞는다. DIMENSION text override나 축척으로 틀린 geometry를 숨기지 않는다.

기존 913개 DIMENSION 보존 pass는 원본 CAD→crop→DWG 재열기의 손실 검사다. 준공도면 치수의 완전성이나 실물 mm 정확도를 증명하지 않는다. 새 검사는 치수 coverage, 미판독/충돌 수, 치수별/최대 residual과 체인 폐합 오차를 보고한다.

## 작업자 순서에 맞춘 생성

`전유부/방향 승인 → 중심선·연결 그래프 → 치수 배치와 전체 구조 제약 → 벽 두께/양면선 → 문·창·디테일 → CAD 치수 재생성 → 검수`

중심선은 뼈대이며 마감면 치수와 같지 않다. 측정 기준과 wall thickness offset을 명시해 전체 길이·간격·연속 치수·연결 조건을 함께 풀어 좌표를 정한다. 직교·평행은 근거가 있을 때만 적용하고 경사벽·곡선을 보존한다. 치수 충돌은 자동 평균 처리하지 않고 근거와 영향 영역을 보여준다.

각 단계 preview, entity/constraint 잠금, 수정·undo·국소 재계산을 제공한다. 사람에게는 경계·반전·치수 판독/연결의 불확실한 항목을 먼저 확인받는다. 최종 DWG로 실제 작업 순서를 알 수 없으므로 이 순서로 파생한 trajectory는 합성 감독으로 표시한다.

먼저 5개에서 정답 표현과 완료 검사를 고정한다. 전체 특징점 대응 성공은 통과 조건이 아니다. 평가 범위는 전유부이며 옆집/공용부 출력 혼입·잘못된 반전·치수 누락과 geometry residual을 별도 보고한다. 미라벨 문맥 영역을 배경 정답으로 일괄 처리하지 않는다.

## 현재 구현과 제한

기존 정합기의 다대일 대응을 발견해 양방향 ratio match·중복 좌표 제거·양쪽 공간 분포 검사를 추가했다. 한 점 수렴 거부와 정상 합성 변환 유지 등 단위 테스트 9개를 통과했다. 사용자 중단 요청에 따라 실제 40개 재정합은 하지 않았으며 기존 report/manifest/receipt도 수정하지 않았다. 이 보강을 전유부·반전·치수 복원 성과로 해석하지 않는다.

원본은 읽기 전용이며 신규 annotation/run은 별도 비공개 경로에 둔다. 기존 추출 CAD는 검수 참고 자산이다. 원장/solver/UI 개선과 직원 승인 검수는 다음 구현 작업이다.
