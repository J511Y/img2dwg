Private first image-to-vector experiment. Upload a floorplan, crop the exclusive
unit, inspect scalable SVG, and download editable DXF and prediction coordinates.

Checkpoint revision and SHA256 are pinned in Space variables. Inference has no
access to the source CAD dataset. Predicted geometry is generated by the trained
coordinate decoder, not by CAD retrieval, a mask contour, or embedded raster.

Training domain is synthetic renders from corporate before-state CAD copies.
Real scan generalization, numeric dimension recognition/association, complete
door/window semantics, exclusive-unit automation and native DWG export are not
established. Native dimension candidates use an explicit unknown `?` value.
Without a human scale anchor the DXF has INSUNITS=0, not an invented mm scale.

Crop selection and inferred unit width are distinct: enter the actual width of
the entire selected image rectangle only if known. All predictions need review.
